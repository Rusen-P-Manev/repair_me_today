# Repair Me Today - Kiosk System (v1.0)

**RepairMeToday** е цялостна уеб-базирана система за управление на автосервиз. Проектът е разработен като "Kiosk" решение, предоставящо интуитивен интерфейс за служителите на сервиза и възможност за публично проследяване на ремонтите от страна на клиентите.

## Основни функционалности

### Работно табло (Dashboard)

- Бърз преглед на активните ремонти.
- Статистика за завършени поръчки, брой клиенти и автомобили.
- Бутони за бърз достъп до основните операции.
    

### Управление на Гараж

- **Клиенти**: Поддръжка на физически и юридически лица (с ЕИК/Булстат и данни за фактуриране).
- **Автомобили**: Пълна информация за автомобила, включително VIN номер и валидация на годината на производство.
    

### Процес на Ремонт (Repair Workflow)

- **Работни карти**: Детайлно описание на проблема, статус на ремонта и автоматично генериране на уникален код за проследяване (UUID).
- **Части и Труд**: Добавяне на резервни части (със статус на поръчката) и услуги от предварително дефиниран каталог.
- **Публична проверка**: Клиентите могат да проверяват статуса на своя ремонт чрез регистрационен номер и предоставения им уникален код, без нужда от регистрация в системата.
    

###  Фактуриране и Архивиране

- **Генериране на фактури**: Автоматично изчисляване на суми и ДДС на база вложените в ремонта части и труд.
- **Профил на сервиза**: Настройка на банкови данни, ЕИК и адрес за издателя на фактурите.
- **JSON Архив**: При маркиране на фактура като платена, системата създава детайлен архивен запис (Snapshot) на целия ремонт в JSON формат, който се пази дори ако оригиналните данни бъдат променени.

##  Технологичен стек

- **Backend**: Python 3.x, Django 6.0.3
- **Database**: PostgreSQL (използван чрез Docker контейнер)
- **Frontend**: HTML5, CSS3, Bootstrap 5.3.2
- **Security**: `python-dotenv` за управление на секретни ключове и пароли.
- **Validation**: Специфични валидатори за VIN, ЕИК, IBAN и български телефонни номера.
****
## Структура на проекта

- `config/`: Основни настройки и URL конфигурация на проекта.
- `common/`: Споделени миксини, валидатори и помощни функции.
- `garage/`: Логика за управление на клиенти и техните превозни средства.
- `repairs/`: Ядрото на системата – работни карти, части, услуги и архиви.
- `invoicing/`: Модул за издаване на фактури и профил на сервиза.
- `employees/`: Управление на персонала.
- `templates/`: HTML шаблони, разделени по приложения.

##  Инсталация и настройка

1. **Клонирайте хранилището**:
    
    ```Bash
    git clone https://github.com/Rusen-P-Manev/repair_me_today.git
    cd repair_me_today
    ```
    
2. **Създайте и активирайте виртуална среда**:
        
    ```Bash
    python3 -m venv .venv
    source .venv/bin/activate  # За Linux/macOS
    # или
    .venv\Scripts\activate     # За Windows
    ```
    
3. **Инсталирайте зависимостите**:
 
    ```Bash
    pip install -r requirements.txt
    ```
    
4. **Конфигурирайте променливите на средата**:

   Копирайте файла .env.example и го преименувайте на .env (или просто изтрийте разширението .example). 
   За целите на проверката и локалното тестване, файлът .env трябва да изглежда така:
	
    ```env
    SECRET_KEY=EZbjfJwNvSI6fZlRRlk8zLFtA9xIVeGH
    DB_NAME=repair_me_today_db
    DB_USER=postgres
    DB_PASSWORD=admin
    DB_HOST=localhost
    DB_PORT=5432
    ```
   *Важно: За да стартирате проекта успешно, моля създайте празна PostgreSQL база данни с име repair_me_today_db,потребител postgres и парола admin. Ако вашият локален Postgres сървър изисква други данни, просто ги подменете в .env файла.*   

5. **Изпълнете миграциите**:

    ```Bash
    python manage.py makemigrations
    python manage.py migrate
    ```
    
6. **Създайте Superuser (Админ)**:

    ```Bash
    python manage.py createsuperuser
    ```
    
7. **Стартирайте сървъра**:

    ```Bash
    python manage.py runserver
    ```
---
### Първи стъпки (Важно!)
След като стартирате сървъра, влезте в административния панел на адрес `/admin/` с вашия Superuser и вкарайте следните данни, за да работи системата коректно:

1. **Профил на сервиза (Invoicing -> Shop Profile)**: Създайте един запис с данните на вашия сервиз (Име, ЕИК, ДДС номер, IBAN). Тези данни се използват автоматично при генериране на фактури.
2. **Служители (Employees -> Employees)**: Добавете поне един служител. Той е необходим, за да можете да отваряте работни карти (поле "Приел автомобила").
3. **Каталог Услуги (Repairs -> Services)**: Можете да добавите стандартни услуги (напр. "Диагностика", "Смяна на масло") в каталога, за да ги добавяте бързо към ремонтите.
